# Resume

This file is reserved for the owner-approved public resume.

The resume should be pasted here only from a version already reviewed for
public disclosure. Before publication, review it again in the context of this
repository because combinations of project details, career history, employers,
dates, tools, and domain language can create inferences that were not present
in the resume alone.

Suggested handling:

- Keep the authoritative resume in this file so visitors do not have to infer
  the owner's background from project text alone.
- Remove or generalize sensitive client, customer, program, location, and
  operational details.
- Prefer capability language over attribution to specific protected programs.
- Link to this file from the README and public profile text.
- Avoid duplicating the full resume in multiple places; summarize it elsewhere.
